# Logolar

Her logo, `config/sirketler.json` içindeki `logo` alanında yazan dosya adıyla bu klasöre konur.

- Biçim: PNG, şeffaf veya beyaz arka plan, en az 600 px genişlik.
- Zorunlu: `kalyon-enerji.png` (varsayılan logo; tüm zincirlerin son halkası).
- Diğer dosyalar opsiyoneldir. Bir şirketin logosu yoksa `logo_yedek` (varsayılan olarak `kalyon-enerji.png`) kullanılır.

Beklenen dosya adları: kalyon-enerji.png, kalyon-gunes.png, kalyon-yeka-res-3.png, kalyon-yeka-res-4.png, kalyon-yeka-ges-3-4.png, kalyon-yeka-ges-5.png, karapinar-eib-yonetici.png, kalyon-isletme.png, kalyon-ev.png, kalen.png, melet.png
